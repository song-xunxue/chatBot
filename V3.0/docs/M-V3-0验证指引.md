## 第 1 步:放行 6099 端口(腾讯云安全组)

服务器 43.140.219.99 的 WebUI(6099)公网访问被腾讯云安全组拦了。两种方式二选一:

### 方式 A:腾讯云控制台放行(推荐,直接浏览器访问)
1. 登录腾讯云控制台 → 云服务器 → 找到 43.140.219.99 实例 → 安全组。
2. 添加入站规则:协议 TCP,端口 `6099`,源 `0.0.0.0/0`(或限你的 IP)。
3. 浏览器访问 `http://43.140.219.99:6099/webui?token=6f4bce131e46`。

### 方式 B:SSH 隧道(更安全,不暴露公网)
在你本地电脑跑:
```bash
ssh -i D:/code/Git_Local/ChatBot/.claude/ubuntu.pem -L 6099:127.0.0.1:6099 ubuntu@43.140.219.99
```
保持窗口开着,浏览器访问 `http://127.0.0.1:6099/webui?token=6f4bce131e46`。

## 第 2 步:WebUI 扫码登录小号

1. 进 WebUI 后,「添加 QQ」→ 选择**扫码登录**。
2. 用你准备好的**验证用小号**(非 6 年老号)的 QQ 手机端扫码。
3. 登录成功后,WebUI 显示小号在线,左侧出现已登录账号。

> ⚠️ 真正生产再决定是否用 6 年老号;**验证期务必用可损失的号**。

| 启用 | ✅ |

保存后,NapCat 会主动连 echo。**echo 日志应出现 `[连接] NapCat 已连上`**。

## 第 4 步:测试收发(echo)

用你的**主号**(或任何号)加小号为好友,私聊小号发一条消息(如「测试」)。
- **预期**:小号立刻 echo 回复同样内容「测试」。
- **echo 日志**(`tmux attach -t echo` 看实时,或 `cat ~/napcat-test/echo/echo.log`)应出现:
  ```
  [收] 你的昵称(你的QQ号) msg_id=xxx: 测试
  [发] echo -> 你的QQ号: OK | 内容: 测试
  ```

## 第 5 步:7 天风控观察清单

验证期 = 7 天,重点观察「小号是否被腾讯风控」。**每日检查**:

- [ ] 小号能否正常收发(echo 是否还能回)。
- [ ] QQ 手机端有无「账号在异地登录」/「账号被冻结」通知。
- [ ] NapCat 容器日志:`docker logs napcat-v3 --tail 50` 看有无「掉线」「被踢下线」「风控」字样。
- [ ] echo 日志:连接是否频繁断开重连(频繁掉线 = 风控前兆)。

**风控分级**:
| 现象 | 等级 | 处理 |
|---|---|---|
| 一切正常,7 天稳定 | ✅ 可接受 | 进 M-V3-1(接 V2.0 核心逻辑) |
| 偶尔掉线,扫码/重登后恢复 | ⚠️ 轻度 | 加固防风控后进 M-V3-1 |
| 被冻结(数小时~3天) | 🔴 中度 | 解封后加强养号 + 降频;评估是否值得继续 |
| 永久封号 | ⛔ 严重 | 放弃或换更稳方案(Lagrange);老号绝不上 |

## 常用运维命令

```bash
# SSH 进服务器
ssh -i D:/code/Git_Local/ChatBot/.claude/ubuntu.pem ubuntu@43.140.219.99

# 看 echo 实时日志(tmux 会话)
tmux attach -t echo        # 进入;Ctrl+B 再按 D 退出(不停止)
cat ~/napcat-test/echo/echo.log   # 或看日志文件

# 看 NapCat 日志
sudo docker logs napcat-v3 --tail 50 -f

# 重启 NapCat(小号掉线时)
cd ~/napcat-test/napcat && sudo docker compose restart

# 重启 echo(改配置后)
tmux send-keys -t echo C-c        # 停
tmux send-keys -t echo 'cd ~/napcat-test/echo && ./venv/bin/python echo_test.py' Enter  # 启

# 停掉整个 M-V3-0(不影响 V2.0)
cd ~/napcat-test/napcat && sudo docker compose down
tmux kill-session -t echo

# 内存监控(NapCat 占用偏高时)
free -h && sudo docker stats --no-stream napcat-v3
```

## 决策点(7 天观察后)

- **风控可接受** → 进 M-V3-1(适配器抽象 + OneBot 出站,接 V2.0 核心逻辑),生产再决定用老号还是小号。
- **风控不可接受** → 放弃 V3.0,保持 V2.0 官方机器人;或试 Lagrange(纯协议,可能更稳)。
