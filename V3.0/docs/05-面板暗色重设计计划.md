# V3.0 Web 面板暗色重设计计划(仿 NapCat WebUI)

> 制定:2026-09-15 · 执行:2026-09-16 凌晨(定时任务) · 状态:待执行
> 用户需求原话:"针对web面板进行优化,仿照Napcat,暗灰色,流式浮动等"

## 一、目标与基调

把现有亮色 Naive UI 面板重皮肤为 **NapCat WebUI 风格**:暗灰近黑底、圆角卡片分区、
克制的荧光绿点缀、流畅的浮动/过渡微交互。**行为零改动**——纯视觉层重构,不碰任何
API 调用、轮询逻辑、业务状态;16 个前端测试不改断言(只改 mock 无关的样式层)。

### 设计语言(仿 NapCat)

- **色板**(CSS 变量统一,见阶段1):
  | 用途 | 值 |
  |---|---|
  | 页面底色 --bg | `#111114` |
  | 卡片/面板面 --card | `#1a1a1f` |
  | 二级悬浮面 --card-2 | `#222228` |
  | 边框 --border | `rgba(255,255,255,0.08)` |
  | 主色 --accent | `#3fc68a`(NapCat 系荧光绿,hover 亮至 `#5bd6a0`) |
  | 正文 | `rgba(255,255,255,0.82)` / 次要 `rgba(255,255,255,0.45)` |
  | 危险 | `#e5484d`(掉线横幅/删除) |
- **形态**:内容区全部卡片化(圆角 12px、1px 暗边框、悬浮阴影 `0 4px 16px rgba(0,0,0,.35)`)
- **流式浮动**:
  - 卡片 hover 上浮(transform: translateY(-2px) + 阴影加深,120ms ease-out)
  - 路由切换 fade-slide 过渡(~150ms)
  - 对话流新消息渐入(animation: msg-in,从 translateY(6px)+opacity 0 进入)
  - 掉线横幅改为顶部浮动胶囊,drop-in 动画
  - 所有动画尊重 `prefers-reduced-motion`

## 二、实施阶段

### 阶段 1:全局暗色主题(地基,1~1.5h)

1. `App.vue`:`<n-config-provider :theme="darkTheme" :theme-overrides="overrides">`
   (overrides 定制 primaryColor=accent、圆角、字体等,对齐全部 naive 组件)
2. 新建 `src/styles/theme.css`:定义上述 CSS 变量 + 全局 body/#app 底色;
   `main.ts` 引入;`index.html` 加 `<style>body{background:#111114}</style>` 防白闪
3. `src/styles/animation.css`:统一的过渡/浮动/渐入 keyframes 与工具类(card-hover、
   msg-in、page-fade),供各页复用

### 阶段 2:PC 布局(MainLayout 仿 NapCat 侧栏,~1h)

- 侧栏:顶部 logo 区(「清浔 3.0」+ 绿色状态点=napcat-status online),
  菜单项圆角高亮(active 背景胶囊),底部小字版本/时间
- 顶栏:标题 + oid 输入 + 登出;掉线横幅改为顶栏下方浮动胶囊(红点呼吸动画)
- 内容区:各页视情况外包一层卡片容器(优先改 MainLayout 的 n-layout-content
  内衬 padding+卡片背景,减少逐页改动)

### 阶段 3:17 页硬编码色清扫(体力活,1.5~2h)
