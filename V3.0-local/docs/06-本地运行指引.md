# V3.0 本地运行指引(Windows 单机 · 面板经局域网供手机访问)

> 一条命令在本机跑起 V3.0 全套(API + 面板同端口),免 Docker、免真实 Redis。

## 前置条件

| 项 | 说明 |
|---|---|
| Python | conda `mychat` 环境,完整路径调用:`C:/Users/26904/anaconda3/envs/mychat/python.exe` |
| 前端产物 | `V3.0/dashboard/dist/` 已构建(缺失时启动会提示先 `npm run build`,API 不受影响) |
| Redis(可选) | 本机若有(如 Memurai/Docker redis)设 `REDIS_URL` 指过去;没有则自动回退 fakeredis(内存态,退出即清) |

## 启动

> 一键脚本(自动拉起 Ollama + 新窗口起服务 + 就绪汇总)与全本地组件编排/显存约束见 `07-全本地运行.md`;以下为手动裸启方式。

```bash
C:/Users/26904/anaconda3/envs/mychat/python.exe V3.0/server/scripts/local_dev.py
```

| 参数 | 默认 | 说明 |
|---|---|---|
| `--port` | 8091 | 与线上 V3.0 同端口;本机 8091 已被占用时换 `--port 18091` |
| `--host` | 0.0.0.0 | 监听全网卡(局域网可达的前提) |
| `--no-seed` | 关 | 跳过 demo 会话/评分/mood 示例种子(默认人设与 mood 5 档由 lifespan 幂等自带,不受此开关影响) |
| `--token` | 无 | 覆盖面板登录 token(须在配置加载前生效,脚本已处理) |

启动打印包含:redis 模式(REAL/FAKEREDIS)、种子结果、**局域网访问地址**(自动探测本机 IP,如 `http://10.170.5.251:8091`)、生效的 `ACCESS_TOKEN` 及其来源。

## 手机访问

1. 手机与电脑连**同一局域网**(同一 WiFi)。
2. 浏览器打开启动日志里的 `http://<局域网IP>:<port>`,用打印出的 `ACCESS_TOKEN` 登录(面板与 API 同源同端口,不受 CORS 限制;局域网**其它**页面直调 REST 才需配 `CORS_ORIGINS`)。
3. 首次启动 Windows 防火墙可能弹"允许访问",需勾选允许;若未弹且手机打不开,管理员 PowerShell 放行:
   ```powershell
   netsh advfirewall firewall add rule name="V3.0 local dev" dir=in action=allow protocol=TCP localport=8091
   ```

## 行为边界(本地能做什么)

| 能 | 不能 |
|---|---|
| 面板全套操作(会话/历史/mood/人设/导出/批注查看/对话控制) | 真 QQ 收发闭环(需 NapCat 反向 WS 连入,本地不跑 NapCat) |
| REST API 全量(`X-Access-Token` header 或 `?token=`) | LLM 自动回复(需 provider key 且网络可达,本地 key 未配则不回) |
| 评分/训练数据相关页面的查看与导出 | TTS 合成(GPT-SoVITS 经 frp,本地默认不可达,仅出站时才触发) |

本地启动后 NapCat 掉线监控会打一条 `WARNING`(WS 未连),属预期噪音,不阻塞服务;后台维护循环(mood 衰减/遗忘)延迟 60s/6h 才启动。

## 冒烟验证

```bash
curl http://127.0.0.1:8091/health                                        # 无鉴权,期望 {"status":"ok",...}
curl -H "X-Access-Token: <token>" http://127.0.0.1:8091/api/v1/chat/sessions   # 期望返回种子会话列表
curl http://127.0.0.1:8091/                                              # 面板首页,期望 200 HTML
```

自动化冒烟:`tests/test_local_dev.py`(fakeredis 回退注入/种子幂等/TestClient 起 lifespan 打接口),随全量套件跑:`cd V3.0/server && <mychat python> -m pytest -q`(当前 511 passed)。
