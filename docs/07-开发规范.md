## 1. 适用范围

适用于 `server/`（FastAPI + Vue 面板）、`client/`（PySide6）、`shared/`、`scripts/` 全部代码与文档。与全局规范一致处不赘述，仅补项目特定条款。

## 2. 项目类型与头部注释

本项目为**项目类型**，所有代码文件头部统一采用项目类型风格：

```python
"""
模块功能说明

作者: 李文煜
日期: yyyy-mm-dd

yyyy-mm-dd
变更说明：
  1. 具体修改内容描述
"""
```

- 新建文件作者填「李文煜」；发现旧文件非该署名主动修正。
- Vue/TS/JS 用 JSDoc `/** */` 等价结构；配置文件（yaml/json）用顶部注释标注用途与作者。

## 3. 代码风格

| 语言 | 规范 | 关键点 |
|---|---|---|
| Python | PEP 8 | 缩进 4 空格、行长 120、snake_case；全量类型注解；async 优先 |
| TypeScript/Vue | ESLint 推荐 | 缩进 2 空格、camelCase；`<script setup lang="ts">` |

- **同级导入不加包前缀**：`from config import ...`，不用 `from server.app.core.config import ...`，兼容直接运行与 `-m` 方式。
- **注释中文**，章节用 `# 1.读取数据` / `# 2.数据预处理` 形式，**不使用** `---`/`====` 装饰线。
- **函数调用注释**：调用第三方库/API 时行内注释说明作用与关键参数。
- **print 避免 Unicode 特殊符号**（Windows GBK 终端）：用 `R-squared`/`m^3`/`deg` 等 ASCII。
- **matplotlib**（若用到）固定配置中文字体 + 负号：
  ```python
  plt.rcParams['font.sans-serif'] = ['Microsoft YaHei', 'SimHei']
  plt.rcParams['axes.unicode_minus'] = False
  ```

## 4. 目录与命名

- 包/模块：snake_case；类：PascalCase；常量：UPPER_SNAKE。
- 资源文件：kebab-case 或 snake_case，语义清晰。
- 目录结构遵循 `02-技术架构` §8。

## 5. 配置与密钥

- 配置用 `pydantic-settings` 从 `.env` 加载；提供 `.env.example` 模板。
- **密钥一律不硬编码、不入库**：API Key、DB 密码、服务器口令、ACCESS_TOKEN 走 `.env`。
- `.gitignore` 必须覆盖：`.env`、`*.db`、`*.sqlite`、`data/`（运行时数据）、`server/data/static/uploads/`（用户上传）。

## 6. 错误处理与日志

- 业务错误抛自定义异常（带错误码，见 `03-接口` §8），全局异常处理器统一转 `{code,message,data}`。
- 外部调用（LLM/Redis/文件）必须 `try/except` + 重试/降级 + 日志。
- 日志：结构化、分级（DEBUG/INFO/WARN/ERROR），关键链路打 `object_id`/`msg_id` 便于追踪。

## 7. 异步与并发

- 服务端全异步（async/await）；IO 密集（LLM/Redis/网络）禁阻塞调用。
- 1 对 1 场景：同一聊天对象消息**串行处理**，避免记忆/状态竞态。
- WebSocket 流式用异步生成器逐 token 推送。

## 8. 测试规范

- `pytest`（服务端核心逻辑）；客户端 UI 关键逻辑可测部分单测。
- 关键模块（管道、记忆评分、遗忘、插件加载）须有单测；`.jbeval/datasets/` 放评测数据。
- LLM 调用测试用 mock/录制，不真实消耗配额。

## 9. Git 工作流

- 分支：`main`（稳定）/ `dev`（开发）/ `feature-*` / `fix-*`。
- 提交信息中文，含模块前缀（如 `feat(memory): 实现遗忘评分`）。
- 双平台推送（Gitee origin + GitHub github），先 origin 后 github；**只提交当前项目目录内文件**；隐私/环境文件不提交。
- 工作目录非 git 仓库，属 `D:\code\Git_Local` 工作区，推送时进入具体子目录操作。

## 10. 文档规范

- 全中文；代码修改同步更新相关文档与 `变更日志`。
- 文档头部统一：文档编号 / 版本 / 作者 / 日期 / 上游引用。
- 接口/数据/字段变更须同步 `03-接口设计` 与 `04-数据模型`。

## 11. 环境与运行

- Python 3.11；优先 conda 环境（`mypytorch`/`langchain`/`coze_env`/`DeepRibo` 之一或新建 `mychat`），通过完整路径调用 `python.exe`。
- 服务端生产用 Docker；本地开发用 `uvicorn ... --reload`。
