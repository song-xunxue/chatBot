## 1. 总体路线

按「文档 → 骨架 → 核心服务端 → 智能层（人设/记忆/插件）→ 客户端 → 面板 → 联调部署」推进。每个里程碑产出**可演示/可测试**的增量，先打通主干（tracer bullet：客户端发消息→服务端→LLM→回显），再横向补全多模态/桌宠/面板。

## 3. WBS 工作分解（节选关键任务）

### M1 骨架
- 1.1 顶层目录 `server/ client/ shared/ docs/ scripts/` + `.env.example` + `.gitignore`
- 1.2 服务端 FastAPI 应用工厂 + 配置加载 + 健康检查
- 1.3 客户端 PySide6 `QApplication` + 主窗口 hello + 托盘
- 1.4 `docker-compose.yml`（redis + server）+ Ubuntu 24.04 部署脚本
- 1.5 CI（lint + test 占位）

### M2 服务端核心
- 2.1 `MessageContext` + 管道 stages + runner
- 2.2 `LLMProvider` 抽象 + glm/deepseek/siliconflow 实现 + registry
- 2.3 Redis 封装（聊天/状态键结构）
- 2.4 WebSocket 端点（信封、流式）+ REST 骨架

### M3 人设 + 记忆
- 3.1 人设 JSON Schema + CRUD + 导入兼容 `persona_*.json` + 图片上传
- 3.2 三级记忆存储 + 编码/检索/注入
- 3.3 遗忘评分 + 手动遗忘 + 记忆查看接口

### M4 插件（✅ 完成；先模板后插件：M4.2 模板先行，再基于模板开发具体插件）
- 4.1 插件内核：PluginManager(发现/加载/实例化/reload) + EventBus(6 钩子 on_message_in/before_llm/after_llm/message_out/tick/delete + 优先级 + 中断 + 异常隔离) + PluginManifest 解析 + Plugin 基类 + 生命周期
- 4.2 插件开发模板 + 配置开关：`plugins/_template/`(plugin.yaml + plugin.py + README) + 可跑示例插件 + 全局开关/按对象配置 REST + 模板测试
- 4.3 五类需求插件：tts(F-P-01) / image_gen(F-P-02,日上限) / sticker_gen(F-P-03) / reply_enhance(F-P-05)，基于模板，各带测试
- 4.4 人性化插件：mood_dynamic / time_aware / proactive_msg / persona_evolve(消费 M3 persona pending 负样本)，基于模板

### M5 客户端
- 5.1 聊天主窗口 + 消息气泡 + 输入栏 + 附件
- 5.2 WS 客户端（重连）+ REST 客户端
- 5.3 SQLite 缓存 + 增量同步 + 保存上限清理

### M6 桌宠 + 多模态
- 6.1 桌宠透明置顶窗口 + 白色圆圈动画 + 点击切换 + 收消息抖动
- 6.2 图像/语音识别（多模态 LLM / ASR）
- 6.3 表情包导入（JPG）+ 自主查找选用 + 聊天背景设置

### M7 面板
- 7.1 Vue3+Vite+TS 工程 + 路由 + 鉴权
- 7.2 人设管理 / 插件管理 / 模型配置 / 历史 / 代人聊天 / 记忆查看

### M8 部署与评测
- 8.1 Ubuntu 24.04 部署（Docker）、进程守护、Redis 持久化、备份脚本
- 8.2 端到端联调、性能/稳定性验证
- 8.3 `.jbeval` 评测数据集与脚本、文档收尾
